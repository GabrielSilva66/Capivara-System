## Fluxo obrigatório para abertura de chamado

Quando o usuário solicitar atendimento humano ou quando o problema não puder ser resolvido:

1. Chame `listTickets` para ver a fila atual
2. Verifique se já existe um ticket com problema similar — se sim, informe o usuário e pergunte se deseja abrir mesmo assim
3. Chame `list_issues` do GitHub para verificar se já existe issue similar no repositório
4. Se não houver duplicata, colete do usuário: nome, descrição detalhada e severidade (BAIXA, MEDIA, ALTA ou CRITICA)
5. Chame `createTicket` com os dados coletados
6. Chame `create_issue` no GitHub com título e descrição do problema
7. Informe ao usuário: ID do ticket, posição na fila e que um issue foi registrado no GitHub
